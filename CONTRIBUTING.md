# Contributing

Thanks for helping improve App Bridge Homepage.

## Setup
```bash
pnpm install
pnpm run dev        # frontend
cp api/.env.example api/.env
pnpm run dev:api    # contact API (optional)
```

## Pull requests
- Branch from `main`, keep PRs small
- `pnpm run build` must pass (CI enforced)
- Korean/English both fine in issues and PRs
